# IT 2750 - Scripting Fundamentals for Cybersecurity
## Lab 1 - Introduction to Scripting with Python

### 🗒  Description
This repository contains the Python script for Lab 1 of the course IT 2750 - Scripting Fundamentals for Cybersecurity. There is one problem in this lab.

In this introductory lab, you will dive into the fundamentals of scripting using Python. The lab consists of one problem, Problem 1, designed to help you become acquainted with the basics of Python scripting. Your main objective is to print specific text to the screen. In Part A, you will print the string "This is Problem 1 of Lab 1." In Part B, you'll print your name, and in Part C, you'll print your Tri-C email address. This lab serves as a foundational exercise for scripting fundamentals.

To successfully complete the lab, make sure to replace the placeholders in the code file headers with your name and Tri-C email address. Testing is also supported with corresponding test files for each problem. Grading for the lab is based on successfully passing assertions in the test files, with Problem 1 being worth 20 points. Ensure your code adheres to the requirements and passes all tests to receive full credit for the lab. Get ready to embark on your scripting journey!
